## Overview

This week saw intense development activity across 7 repositories with 111 total commits and 300 GitHub events. The biggest milestones were a comprehensive UI overhaul for AutoClaude and the launch of user accounts for the chess platform. Development work spanned UI enhancements, API development, workflow automation, and project management tooling.

## AutoClaude (10 commits)

AutoClaude received major attention this week with a complete redesign of its tab interface. The tool now provides much richer visibility into Claude Code sessions and task management.

**Permission Profiles tab** got a complete makeover, replacing the simple tab-based selector with rich profile cards. Each card now displays the profile name, description, mode, usage count, and tool summaries. Tools are managed via tag-style selectors where you can click to toggle between allowed (green), blocked (red), and unset (gray). The UI includes a default profile badge with a star button, duplicate profile functionality, and JSON import/export capabilities.

**Claude Locations tab** is now fully functional, tracking all Claude Code sessions from the Desktop app. Sessions are organized into three groups: Running (with a green glow effect), Recent (idle sessions), and Archived (dimmed). Each card shows session title, project name, working directory, and relative time stamps, along with status tags for the model name and permission mode. The tab auto-refreshes every 15 seconds and displays running session counts in both the tab badge and header.

**Projects tab** got built out with a comprehensive project and task management interface. Project cards now show activity status indicators (active/idle/complete/empty) and meta tags for main directories, SSH locations, CLAUDE.md paths, and GitHub repos. Each project card includes a grouped task list with status dots, and there's an Unassigned Tasks section with quick assignment dropdowns.

The **Usage Monitor tab** was enhanced with three distinct sections: Connection Status (with re-auth form), Plan Usage (utilization bars and chart), and Overnight Management (schedule controls with credit reset countdown timers and an overnight execution queue).

## Chess Platform (85 commits across 3 repos)

### chess-api (25 commits)

The big news here is **v1.04.0000: User Accounts** feature merge. This comprehensive PR introduced authentication, user profiles, ratings, and friends functionality. The API now supports full user account management with profile data and social features. Documentation was also updated with improved deployment instructions that read tokens from files.

### chess-client (30 commits)

The client received numerous updates to support the new user accounts feature, with UI refinements to match the header design language. Work also included infrastructure improvements like pinning Claude Code to v2.1.18 to avoid an SDK AJV crash. A weekly chess update blog post was generated, showing the project is using similar automated blog workflows.

### chess-project (30 commits)

Heavy project management work happened in the chess-project repo. The CLAUDE.md file was enhanced with instructions for branch cleanup, PR delete-branch handling, and item archival. WebSearch and unrestricted WebFetch permissions were added to support broader automation capabilities. Session naming enforcement was also strengthened to maintain consistency across Claude Code sessions.
